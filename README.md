# Project name : Monthly Expense Tracker

**Author(s):** Ji Choi

## Project plan

### Project idea

The Monthly Expense Tracker is a browser-based application that helps users keep track of their expenses.
The user can enter an expense by adding the amount, category, date and a short description. The application stores the expenses and displays a summary showing how much money has been spent in total and how the spending is divided between different categories.
The user can view expenses for a selected month and see how much was spent in each category.

### Planned features

The application will allow the user to:

- Add a new expense
- Enter the expense amount
- Select a category
- Enter a short description
- Select the date of the expense
- Delete an expense
- View the total amount spent during the selected month
- View spending totals by category

Example expense categories:

- Groceries
- Transportation
- Restaurants
- Shopping
- Entertainment
- Bills
- Other
